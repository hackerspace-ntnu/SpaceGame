# Station table

The table of [Stations.md](Stations.md), written from the data by `StationTable` (**Tools > SpaceGame > Residents > Write Station Table**), and the two things
the data cannot say by itself: how close each clip is to its job, and where each work action puts its work.

## Model

Source of truth: the `SpotUse` and `SettlementSpot` assets, `StationAuthoring`, the actions' `Reach`. This file is output plus notes; `StationTableTests` fails when the table is stale.

## Key types

| Type | Role |
| --- | --- |
| `StationTable` ([StationTable.cs](Assets/Game/Scripts/agents/Residents/Editor/StationTable.cs)) | builds the rows and rewrites the table between the markers |
| `ActionReachMeasurer` ([ActionReachMeasurer.cs](Assets/Game/Editor/Animation/ActionReachMeasurer.cs)) | measures each work action, **Tools > SpaceGame > Animation > Measure Action Reach** |

## Flows

### The table

Generated; do not edit between the markers. `Target` is spots with a `face` of all spots of that kind on that cue; `Stand to target` is the authored distance
(and the measured reach of the cue's loops); `Status` is derived: `ok`, `stands` (no cue), `MISSING CLIP` (a cue no loop fits) or `TOOL MISMATCH`
(a worker whose post this is carries none of the tools the clips are made for).

### Reach, measured

`ActionReachMeasurer` plays every work action through the real humanoid controller on a real Raxy (`Raxy_handyman`, edit-mode `Animator.Update`, 60 samples of one cycle, no Play mode)
and stores on the action where the work lands relative to the body root (x right, y up, z forward, metres), and for a strike each variant's Contact time (`Variant.contactAt`).

**What is tracked is the hand, not the tool.** A tool's grip is fitted to the Carry pose, not to the work clip, so a tool on the real rig points where its carry grip points (a hoe's tip came
out 1.7 m in the air with the hand on the ground). The hand's grip point is certain. For a **ground strike** the tool's end is *estimated* on the floor (its length beyond the grip, from the hand
down to the floor), a **wall swing** holds the tool level, a **bench strike** points it down; continuous work reports the hand, which understates a tool in it. Contact is the hand's lowest
(`GroundStrike`, `LowestHand`) or farthest (`FarthestHand`) point, not always an impact: Mine Wall and some Mine Ground and Hammer Ground variants pass it fast (hand speed at contact several
times the median), so there it marks the swing's extreme. The exit check (`StationReachTests`) asserts only strikes; the hand of continuous work is reported, not asserted.

## Persistence

None.

## Gotchas

- **The table is generated.** Edit the data, then run *Write Station Table*; the test compares the file with what the data makes.
- **Hand-tracked reach understates a tool** and a strike's contact is the hand's extreme, not always an impact; re-measure when the grips are refit to the work clips.
- **Status is derived, notes are not.** `ok` means a loop fits and the workers carry the tool; it does not mean the clip is the right job: read the notes table.

## Extending

A new kind of spot appears in the table by itself. A new work action: add it to `ActionReachMeasurer.Jobs` (rule, tool), run the measurer, run *Write Station Table*, then correct the notes table by hand.
